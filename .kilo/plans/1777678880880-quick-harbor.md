# Plan to Remove paradoxia_stubs.c and Fix Link Errors

## Problem Analysis
The paradoxia_stubs.c file was created to provide stub implementations for functions from deleted content (Battle Frontier, Contest, Trainer Hill, etc.) to prevent linker errors. Removing this file causes undefined reference errors because the code still calls these functions.

## Objective
Remove paradoxia_stubs.c and eliminate the references to the functions it was stubbing, by removing unnecessary code as deemed appropriate by the GDD.

## Strategy
1. Identify which systems should be completely removed based on GDD references
2. Locate source files containing calls to functions from these systems
3. Remove or disable those calls (or remove entire files if appropriate)
4. Verify successful compilation

## Systems to Remove (Based on GDD)
From the GDD, these systems appear to have been removed:
- Contest system
- Battle Frontier system  
- Trainer Hill system
- Battle Pyramid
- Battle Pike
- Battle Arena
- Battle Dome
- Battle Tent
- Secret Basements
- TV shows
- Frontier minigames

## Implementation Plan

### Phase 1: Identify Reference Files
Search for files containing references to the undefined functions we saw in the build error:
- gContestResources, LoadContestBgAfterMoveAnim, etc. (Contest)
- GetFrontierTrainerFrontSpriteId, etc. (Battle Frontier)
- GetTrainerHillTrainerFrontSpriteId, etc. (Trainer Hill)
- And others...

### Phase 2: Modify Source Files
For each file containing unwanted references:
- If file is entirely related to a removed system: remove the file
- If file contains mixed content: comment out or remove specific function calls
- Replace calls with stubs that do nothing (if removal breaks other functionality)

### Phase 3: Verify Build
Attempt to compile and resolve any remaining issues iteratively.

## GDD-Guided Decisions
When deciding whether to remove code or just specific calls:
- If a file's primary purpose is related to a removed system (per GDD), remove the entire file
- If a file has legitimate purposes plus some removed system calls, remove just the calls
- Follow patterns established in GDD for what was actually removed vs. stubbed
